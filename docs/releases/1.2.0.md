**Works with the desktop app's task list**

In the Claude desktop app, Claude already keeps a task list under its last message. Until now it had to keep a second list for Progress Ring. From 1.2.0 the card follows that task list:

- A task list of three or more steps opens a card, and each step Claude completes closes there.
- The card finishes when the turn wraps up, and replans keep the steps already closed.
- Claude uses the `progress` command only for what the list doesn't carry: iterations, accepting subagent work, cancelling or pausing, and a clearer title.
- Accepting a subagent's work on these cards adds no extra step, since the task list already counts it.
- If Claude also opens a card with `progress start` in the same turn, the list goes into that card, so you never get two.

In the terminal nothing changes.

**Update**
```
claude plugin update progress-ring@progress-ring
```
